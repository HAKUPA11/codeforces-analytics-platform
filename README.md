# Codeforces Analytics Platform

A production-style analytics platform built using the Codeforces API.

## Tech Stack

- MySQL
- Python
- Pandas
- SQLAlchemy
- Requests
- Matplotlib
- Git
- GitHub

## Features (Planned)

- Fetch data from Codeforces API
- Store data in MySQL
- Analyze contests and users
- SQL reports
- Python analytics
- Interactive dashboard
