# Requirements Analysis

## Problem Statement

Competitive programmers use multiple websites to analyze their performance.
Codeforces provides an API, but it does not provide a centralized SQL analytics platform.

This project aims to build a complete analytics platform using the Codeforces API,
MySQL, Python, and SQL.

---

## Objectives

- Fetch real-time Codeforces data
- Design a normalized relational database
- Store contest, user, problem, and submission data
- Perform SQL analytics
- Generate reports using Python
- Build a dashboard

---

## Target Users

- Competitive Programmers
- Students
- Recruiters
- Data Analysts

---

## Data Sources

- Codeforces API

---

## Functional Requirements

- Fetch Users
- Fetch Contests
- Fetch Problems
- Fetch Submissions
- Store Data
- Analyze Data
- Generate Reports

---

## Non Functional Requirements

- Scalable
- Efficient
- Easy to Maintain
- Modular
